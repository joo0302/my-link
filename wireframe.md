# [와이어프레임] 마이링크 메인 화면 (방문자 뷰)

> 토스 디자인 시스템(TDS) 가이드라인을 준수한 **430px 단일 모바일 셸(Shell)** 기반의 방문자 프로필 뷰 와이어프레임입니다.

## 2. 인터랙션 오버레이 (바텀시트 & 토스트)

```text

|                                                             |

|  +-------------------------------------------------------+  |
|  |                    [   ㅡ 드래그 핸들   ]             |  |
```

## 3. 세부 컴포넌트 명세

| 영역 | 컴포넌트 | 기능 및 디자인 규칙 |
|------|----------|-------------------|
| **상단 앱바** | TopBar (56px) | • 좌측: 브랜드 인디케이터(Toss Blue 점) + "마이링크"<br>• 우측: 네이티브 공유 API / 테마 토글(라이트/다크) |
| **프로필 카드** | ProfileCard | • 80px 원형 아바타 (MJ 이니셜 + 온라인 상태 인디케이터 녹색 점)<br>• 이름(20px 볼드) 및 직무 태그<br>• 상태 칩 배지: "새로운 기회와 커피챗을 기다려요"<br>• 보조 액션 버튼 2단 (이메일 복사 / 연락처 보기) |
| **소셜 바** | SocialIconsBar | • 40px 둥근 카드 버튼 가로 정렬<br>• GitHub, Blog, Mail 등록 아이콘만 노출 |
| **링크 목록** | LinkList (ListRow) | • 44px 둥근 모서리 아이콘 컨테이너<br>• 타이틀, 설명, 뱃지, 우측 화살표 `ChevronRight`<br>• `highlight: true` 링크는 토스 블루 테두리/배경 및 "대표작" 뱃지 적용 |
| **하단 액션바** | BottomCTA | • 화면 최하단 고정 버튼 (56px 높이, 토스 블루 색상)<br>• 탭 시 바텀시트 모달 노출 |
| **바텀시트** | BottomSheet | • 상단 둥근 28px 모서리, 부드러운 슬라이드 업 애니메이션<br>• 스크림 클릭 또는 [X] 버튼 클릭 시 닫힘 |
